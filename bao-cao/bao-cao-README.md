## Sửa và xuất lại

File gốc nằm trong [`nguon/`](nguon/), cùng tên với bản PDF (`bao-cao-chuong-trinh.html` là file gốc của `bao-cao-chuong-trinh-da-chay.pdf`). Hình mẫu lấy từ `de-xuat/hinh/`.

1. Sửa chữ trong file HTML bằng Notepad hoặc VS Code.
2. Mở file bằng Chrome, bấm Ctrl+P, chọn "Lưu dưới dạng PDF", khổ A4, bật "Đồ họa nền", tắt "Đầu trang và chân trang". Số trang tự có ở chân trang.
3. Lưu đè lên file PDF trong thư mục này.
